# SDX Solutions UG — Unternehmenswebsite

Die Website positioniert SDX Solutions UG als Anbieter für Softwareentwicklung, mobile Apps, Websites, Webservices, Publishing und IT-Dienstleistungen.

## Lokal ansehen

Die Seite besteht aus statischem HTML, CSS und JavaScript. Zum lokalen Testen kann im Projektordner ein einfacher Webserver gestartet werden:

```bash
python3 -m http.server 4173
```

Danach ist die Website unter `http://127.0.0.1:4173` erreichbar.
